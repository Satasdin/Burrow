Download Burrow

Get started by installing Burrow, or have your agent install it for you. A Mac with Apple silicon: macOS 14 or later for the program, macOS 26 or later for the app.

Install

curl -fsSL https://github.com/Satasdin/Burrow/releases/latest/download/install.sh | sh -s -- --app
Download manually

The installer checks every file against its SHA-256 checksum and stops if one does not match.

Teach your agent to use it

/plugin install burrow --marketplace Satasdin/Burrow

Five skills for Claude Code: carry work on, keep decisions, answer a held change, set up. Other programs: paste AGENTS.md into their instructions.

Then

  1. Pull the embedding model: ollama pull qwen3-embedding:0.6b
  2. Make a folder of notes a vault: burrow vault new ~/Notes
  3. Connect a program: burrow connect claude-code ~/Notes
  4. Read the getting started guide.
