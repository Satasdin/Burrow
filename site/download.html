Download for Mac

Burrow.app · Apple silicon · macOS 26 or later · release notes

Burrow isn't notarized by Apple yet, so the first time you open it macOS will stop it. Open System Settings → Privacy & Security and choose Open Anyway once. The terminal install below doesn't need this.

Or install from the terminal

curl -fsSL https://github.com/Satasdin/Burrow/releases/latest/download/install.sh | sh -s -- --app

The installer checks every file against its SHA-256 checksum and stops if one doesn't match. The terminal program alone needs macOS 14 or later.
