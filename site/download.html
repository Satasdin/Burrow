Download

Download Burrow

Install it yourself, or have your agent do it. A Mac with Apple silicon: macOS 14 or later for the program, macOS 26 or later for the app.

Install

curl -fsSL https://github.com/Satasdin/Burrow/releases/latest/download/install.sh | sh -s -- --app

The installer checks every file against its SHA-256 checksum and stops if one doesn't match. Or download it from GitHub.

Install it with the command on the Burrow download page, pull the embedding model with Ollama, make ~/Notes a vault, and show me what `burrow connect` would change for the programs I use. Approving folders, writing settings and anything Burrow says only I can do: give me the exact command and wait for me.

Teach your agent to use it

/plugin install burrow --marketplace Satasdin/Burrow

Five skills for Claude Code: carry work on, keep decisions, answer a held change, set up. For other programs, paste AGENTS.md into their instructions.

Then

  1. Pull the embedding model: ollama pull qwen3-embedding:0.6b
  2. Make a folder of notes a vault: burrow vault new ~/Notes
  3. Connect a program: burrow connect claude-code ~/Notes
  4. Read getting started.
