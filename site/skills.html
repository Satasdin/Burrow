Skills.

CAMR's tools tell a model what they do. Seven skills teach it to use them well: when to resume, how to keep a decision the next model keeps to, and what to do when a change is held.

/plugin install camr --marketplace Satasdin/CAMR

In Claude Code. For other programs, see installing.

Installing

Claude Code
As a plugin: /plugin install camr --marketplace Satasdin/CAMR. Or copy the folders you want into ~/.claude/skills/.
Skills folders
Any program that reads skills (a folder with a SKILL.md): copy the folders into its skills folder.
Everything else
OpenCode, OpenClaw, Hermes Agent, Cursor and others: paste AGENTS.md, all seven on one page, into the program's instructions file.

The skills need CAMR connected: camr connect <program> ~/Notes. How
